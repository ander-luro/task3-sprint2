# Sprint2 Task S2.01: Data Structure - MongoDB
Exercicis per a aprendre a modelar bases de dades NoSQL

## Tecnologies
- MongoDB
- MongoDB Compass

## Exercici 1 
Dissenyar la base de dades des del punt de vista del client d'una òptica.

## Exercici 2
Dissenyar la base de dades des del punt de vista de les ulleres. 


## Instal·lació i Execució
Per posar en marxa la base de dades a local:
1. Obre MongoDB Compass i crea una nova base de dades.
2. Crea les tres col·leccions necessàries: `clients`, `suppliers` i `glasses`.
3. Importa els fitxers JSON corresponents a cada col·lecció
